# 0064. Etiqueta de cierre `v0.6-hito6`

- **Estado:** Aceptada
- **Fecha:** 2026-11-06

## Contexto

El hito 6 se cierra antes que el 5 ([ADR 0048](0048-hito-6-antes-que-el-5.md)), y las etiquetas de cierre de cada hito siguen el patrón `v0.N-hitoN`.

## Decisión

La etiqueta de cierre es `v0.6-hito6`; la `v0.5-hito5` llegará después. La crea Pedro tras fusionar el PR de la 6.6.

## Alternativas consideradas

- Numerar por orden de cierre (`v0.5-hito6`): la etiqueta dejaría de nombrar el hito, y la siguiente chocaría con el número.

## Consecuencias

- Las etiquetas no van en orden cronológico; cada una nombra su hito.

## Qué cambió al implementarla

Nada.
