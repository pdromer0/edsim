# Diario de aprendizaje

El diario recoge lo aprendido en cada hito: conceptos nuevos, errores y cómo se resolvieron, y dudas que quedan abiertas. Es el registro del aprendizaje; las decisiones de diseño van en [decisiones/](../decisiones/README.md).

Hay un fichero por hito (`hito-0.md`, `hito-1.md`, …). La entrada se escribe al cerrar cada tarea o, como mínimo, al cerrar el hito.

## Formato de cada entrada

```markdown
## AAAA-MM-DD · Tarea N.M — título

**Qué se hizo:** una o dos frases.

**Qué aprendí:**
- Concepto o técnica, explicado con mis palabras.

**Qué costó o falló:**
- Problema, causa y cómo se resolvió.

**Preguntas abiertas:**
- Lo que queda por entender o decidir.

**Enlaces:** PR #N · ADR NNNN · documentación consultada
```
