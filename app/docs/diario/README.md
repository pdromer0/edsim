# Diario de aprendizaje de la app

El diario recoge conceptos nuevos, errores y cómo se resolvieron, y preguntas
abiertas. Las decisiones de diseño van en [decisiones/](../decisiones/README.md).

Hay un fichero por fase (`fase-1.md`, `fase-2.md`, …), con entradas por tarea.
Durante A.1–A.7 las notas se guardan en la sección «Notas para el diario» del PR:
plan, permisos pedidos, errores, sorpresas y consumo disponible. En A.8 se escribe
la entrada de la fase 1, incluida la comparación entre Codex y Claude Code.

## Formato de cada entrada

```markdown
## AAAA-MM-DD · Tarea A.N — título

**Qué se hizo:** una o dos frases.

**Qué aprendí:**
- Concepto o técnica, explicado con mis palabras.

**Qué costó o falló:**
- Problema, causa y cómo se resolvió.

**Preguntas abiertas:**
- Lo que queda por entender o decidir.

**Enlaces:** PR #N · ADR APP-NNNN · documentación consultada
```
